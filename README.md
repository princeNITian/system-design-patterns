# System Design Patterns

> A comprehensive, practical guide to modern System Design patterns, architectural decisions, scalability techniques, distributed systems, and real-world case studies.

This repository is my personal knowledge base for learning **System Design** from the ground up.

The goal is **not just to memorize concepts**, but to understand:

- **Why** a pattern exists
- **What problem** it solves
- **When** to use it
- **When not** to use it
- **Its trade-offs**
- **Real-world examples**
- **Interview relevance**

Instead of learning technologies individually (Kafka, Redis, Kubernetes, etc.), this repository focuses on **design decisions**—the thought process behind building scalable and reliable systems.

# Repository Philosophy

Every topic answers the same core questions:

- What is it?
- Why do we need it?
- What problem does it solve?
- How does it work?
- What are its advantages?
- What are its disadvantages?
- When should we use it?
- When should we avoid it?
- Which companies use it?
- What are the common interview questions?
- What are the alternatives?

The objective is to build intuition for making architectural decisions.
